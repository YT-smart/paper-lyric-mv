# Paper Lyric MV · 纸艺风剧情歌词 MV

**给 AI 一首歌，让纸片小人把歌词演成一个故事。**

会哭会笑的 Q 版角色，层层叠起的剪纸布景，一字一张的纸片字幕。这个 Skill 让 AI 理解歌词里的情绪和人物关系，设计角色与分镜，再制作出搭配歌曲的剧情动画 MV。

从前奏的铺垫，到主歌的展开、副歌的拥抱，再到尾奏的收束，让整首歌成为一个连贯的小故事。

## ✨ 这个 Skill 能做什么

- **先读懂歌，再设计故事**：梳理谁在对谁说话、歌词里的比喻和情绪转折，确定贯穿整首歌的故事线。
- **让纸片角色真正演起来**：Q 版人物有固定造型、配色和标志物，可以眨眼、转头、走路、挥手、哭笑和拥抱。
- **让每句歌词都有对应动作**：按歌词时间轴安排镜头，也为前奏、间奏和尾奏设计铺垫、旅程与回忆。
- **做出有层次的纸艺质感**：彩色卡纸、白色纸芯描边、柔和投影和撕纸边，搭配低饱和配色与淡淡纸纹；回忆段落加入泛黄与照片白边。
- **制作动态纸片歌词**：一个字一张小纸片，逐字弹出，每句用红纸突出一个关键字，并与歌曲时间轴同步。
- **先看方向，再做整首歌**：先确认角色设定和关键静帧，再看约 30 秒动画样片，确认后制作完整版。
- **保留可以继续修改的工程**：交付故事分镜、镜头代码与视频，可以用自然语言修改角色、画面、节奏和字幕。

默认规格为 **1920 × 1080、16:9 横屏、24 fps**，成片搭配歌曲音轨与动态歌词。

## 🚀 快速开始

### 1. 安装 Skill

把下面这句话发给支持 Skill 的 AI 助手：

```text
请帮我安装这个 Skill：https://github.com/YT-smart/paper-lyric-mv
```

安装及制作视频所需的环境由 AI 准备。

### 2. 把歌曲和需求交给 AI

可以提供音频和歌词；有带时间轴的 LRC 歌词更方便。也可以先告诉 AI 歌名，让它按 Skill 的流程确认素材来源。

**用自己的歌曲制作 MV：**

```text
使用 paper-lyric-mv skill，给我提供的这首歌做一个纸艺风剧情歌词 MV。
先讲讲你对歌词的理解，再设计角色和分镜。
先给我看角色设定和关键静帧，确认后再做样片。
```

**先做一段动画样片：**

```text
使用 paper-lyric-mv skill，根据我提供的音乐和歌词，设计一段约 30 秒的纸艺动画。
人物要有表情和动作，每句歌词都要有对应画面。
先看静帧，确认后再渲染视频。
```

**只有歌名，也可以开始：**

```text
使用 paper-lyric-mv skill，给《歌名》做一个纸艺风剧情歌词 MV。
先帮我确认音乐和歌词来源，再给我故事线、角色和分镜方案。
```

**修改已有镜头：**

```text
把副歌的拥抱镜头拉近一点，妈妈的表情更温柔。
歌词不要挡住人物的脸，先给我看修改后的静帧。
```

## 🎞️ 它是怎样制作 MV 的

```text
歌曲 + 歌词
      ↓
理解歌词、确定故事线
      ↓
角色设定与分镜方案
      ↓
定妆静帧 → 确认画面方向
      ↓
约 30 秒动画样片 → 根据反馈修改
      ↓
整首歌的剧情动画 + 纸片歌词
      ↓
合成带歌曲音轨的 1080p MV
```

画面由代码逐帧绘制，角色动作、镜头变化与歌词时间轴对应。前后镜头使用同一套角色设定，围巾、发型、配色等细节帮助观众认出人物；红线、信件、照片等道具可以贯穿故事，连接不同段落。
