# 示例：赵雷《我记得》（5:30）

用法：`node <技能目录>/scripts/init_project.js my-mv --example wojide`，再把这首歌的音乐和 LRC 放进 `assets/`（按 references/music-and-lyrics.md 获取；本示例的时间点按 QQ 音乐原版 LRC 写的）。

## 一句话主题

一个灵魂背着装满前世记忆的包袱来投胎；出生时记忆被剪掉、擦掉，他在妈妈怀里说不出另一个世界的消息。妈妈其实是他每一世都会遇见的人，只是两个人都不记得了。

## 角色（cast.js）

- **小魂（我）**：黄外套，头顶一根小芽，背着大包袱
- **妈妈（今生的你）**：米白长裙，长发，红围巾
- **三段前世**：枣树下的玩伴（红衣马尾）；叔父和侄儿；恋人（蓝裙短发的我，上了战场的你）
- **年轻的外婆**（妈妈的妈妈，已经过世）：白衣，马尾
- **贯穿全片的信物**：包袱里的记忆（枣、铜钱、信、心）、红线、圆圈

## 可以借鉴的技巧

- **用照片进入回忆**（`shotFate`）：墙上相框里先画下一段场景，再推进去放大成全屏。
- **同一首歌里重复的副歌**（`CHORUS` 时间表）：一句“呜”切回婴儿床，一句“快来抱抱”切到某一世的拥抱。
- **对比**（`shotForget`）：两个思考气泡，一个满、一个空。
- **抽象歌词具体化**（`shotCircle`）：把“圆圈”“直行或是转弯”画成圆形小路上两条不同的路线。
- **回收母题**：开头收进包袱的记忆，在产房里一件件飞走；结尾的回忆墙又用红线把它们全部串起来。
