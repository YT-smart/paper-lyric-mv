# 纸艺风格守则

这种风格叫纸艺风（剪纸风）剧情歌词 MV：扁平插画 + Q 版角色 + MG 动画式的弹性运动 + 纸片字幕。下面是让它看起来“精细”而不是“简陋”的做法。

## 1. 材质：一切都是纸

- **每个形状都用 `sheet()` 画。** 它会自动加投影、填色和白色纸芯描边。少了投影就“贴”在背景上，少了白边就不像纸。
- 层次靠叠：天空 → 远山（`tornRidge`，颜色浅）→ 中景树林 → 近景地面（颜色深、投影大）→ 人物 → 前景小物件。每层颜色依次加深，投影 `blur` 依次变大（远 6–8，近 14–18）。
- 撕纸边：地面、山、水面用 `tornRidge()`，它自带细碎的毛边。
- 多个圆拼成一团的东西（树冠、云团、花丛）用 `blobSheet()`：先画整团的白边，再填色，避免里面出现一圈圈白线。
- 纸纹：引擎会在每帧最后自动叠一层很淡的纸纹，不要再额外加重。
- 半透明的东西（光束、窗纱、灵魂）用 `globalAlpha` 0.15–0.6，别用纯白实心块。

## 2. 配色

整体用低饱和的暖色，像彩色卡纸，不要荧光色。

| 情绪 / 场景 | 背景渐变（上 → 下） | 点缀 |
|---|---|---|
| 温暖、家 | `#f4d7c2 → #e9b9a3` | 红 `#d24f45`、木色 `#d9b48f` |
| 夜晚、梦、星空 | `#1f2a4d → #584b7d` | 星星黄 `#f3d27a`、米白云 `#f7f1e6` |
| 水下 | `#4aa3b0 → #2a6f82` | 气泡白、海草绿 `#3f8a6a` |
| 秋天、童年回忆 | `#f2c98e → #f7e2bb` | 枣红 `#c8382f`、金黄 `#b99238` |
| 老街、旧时光 | `#f0d3a2 → #e7b787` | 瓦灰 `#5f4a42`、灯笼红 `#d9473b` |
| 战争、离别 | `#8a5a52 → #c27a5a`，再加压暗 | 烟灰 `#5d5452`、火光橙 `#f2a65a` |
| 医院、新生 | `#d5ebe4 → #bfdcd3` | 薄荷绿 `#8fc4b8` |
| 黄昏城市 | `#f2a37f → #fbd6a0` | 楼体紫 `#7b5a6e`、窗灯黄 `#f9d98a` |

- 回忆段落一律加 `K.memoryLook()`：泛黄滤镜 + 照片白边。
- 同一段里背景色保持一致，换段落时换色调，观众能感觉到“到了另一个地方或时间”。

## 3. 角色

- **比例**：小孩（`kind:'kid'`）头身比约 1:2.5，非常 Q；大人（`kind:'adult'`）头小一些，身体修长。在中景里，孩子 h≈260–300，大人 h≈500–700。
- **脸**：豆豆眼带高光，腮红，嘴是一笔。表情全靠 `expr` 切换，详见 engine-api.md。
- **眨眼**：每个出镜的角色都要传 `blink: blink(t, 不同的seed)`，否则看起来像假人。
- **头朝哪边看**：`turn`（-1 到 1）会让五官偏向一侧，用来表示“看向对方”。两人对话时，左边的人 turn>0，右边的人 turn<0。
- **特写**用 `head()`，再单独画一个肩膀形状（参考 `shotVoice`、`shotPonytail`）。
- **婴儿**用 `baby()`，被抱着时在襁褓上加一只大人的手（肤色椭圆）。
- **不要**用线条拼火柴人，**不要**画写实人体。这两种都是已经被否定过的方向。

## 4. 动作和节奏

- **出现**：`popIn(t, t0)` 带回弹地弹出来，比淡入更有纸片感。
- **走路**：`walk: t*7, walkAmt: 1`，身体会自然起伏；停下时把 `walkAmt` 平滑降到 0。
- **抬手**：`armL` / `armR` 取 0（下垂）到 2.8（举过头顶）。挥手是 `2.6 + Math.sin(t*8)*0.3`。
- **开心**：`hop` 小跳，`expr: 'laugh'`，再冒出爱心（`heart()`）。
- **惊讶**：`expr: 'o'` + `chip('？')` 或 `chip('！')`。
- **拟声**：`chip('咔')`、`chip('咚')`、`chip('z')`，用红字黄底或深字白底。
- **呼吸感**：整组人物加 `Math.sin(t*1.5)*0.04` 的轻微摇晃，背景物件缓慢漂浮。
- **节奏**：动作落在歌词的重音上；副歌里每 1.5–3 秒换一个画面，主歌里一个镜头 4–14 秒。
- **音乐联动**：`E.e`（0–1 的音量能量）可以让星星、灯光、波纹随音乐跳动。用一点点就够了，别让整个画面一直闪。

## 5. 字幕

- 引擎自动画：每个字一张米白纸片，逐字弹出；句末淡出；`HIGHLIGHT` 指定的字用红纸白字。
- **每句只挑一个字标红**，挑这句最有画面感或最戳心的那个字（重、光、剪、你、抱、信……）。一首歌里反复出现的“你”也可以每次都标红，形成记忆点。
- 字幕在画面下方大约 88% 的高度。设计镜头时，这一带不要放人脸和关键道具。
- 需要换字号或位置时，在 `shots.js` 导出 `LYRIC_STYLE`，例如 `{ size: 52, y: 980 }`。某个镜头不想显示歌词，就在镜头对象上加 `noLyrics: true`。

## 6. 怎样算“精细”（自查）

- 背景至少三层，有远近；地面有撕纸边；天上有云或星星
- 画面里有细节：小花、落叶、灯笼、相框、窗外的云
- 人物有表情变化，有眨眼，有朝向
- 每个镜头都有东西在动
- 颜色干净，纸纹很淡，没有发灰发脏
- 没有东西挡住脸，字幕不压人物
- 镜头推进（zoom）对准有内容的地方
