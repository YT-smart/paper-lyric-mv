## 1. 先读懂：歌在讲什么

用户要的不是把歌词一个字一个字图解出来，而是**这首歌真正想说的那件事**。通读 LRC，回答这几个问题：

- **谁在说？对谁说？** “我”和“你”分别是谁？是恋人、父母、朋友，还是过去的自己？要找证据：称呼（“最亲爱的人”）、场景（产房、战场）、时间线。
- **哪些句子是比喻？** 比如“比身体重的行李”，指的是带着前世的记忆；“游入尼罗河底”，指的是进入母体（羊水）；“几个人拿着剪刀”，指的是医生剪脐带；“擦拭我的脑袋”，指的是出生时被擦去记忆。比喻要还原成能画出来的具体事件。
- **情绪怎么走？** 平静 → 疑惑 → 怀念 → 心酸 → 释然，副歌是哪种情绪的爆发？
- **故事的“钩子”是什么？** 就是那个让人恍然大悟的点。《我记得》的钩子是：“你”是妈妈，我们每一世都相遇，却都不记得。最后一句“我终于找到你”，是再次出生到你怀里。

想不清楚时可以搜一下这首歌的创作背景和乐评，但最后要落到自己能讲清楚的一句话主题上。

**写成一句话主题**，例如：
> 一个灵魂带着前世的记忆来投胎，记忆在出生时被抹去；他和妈妈在每一世都以不同身份相遇、分离，最后又在她怀里重逢。

如果歌词本身就很具体（讲日常、讲恋爱），就按字面讲一个温暖的小故事，不用硬找深意。歌词很抽象的时候，选一个能把所有句子串起来的具体故事。

## 2. 定角色

- **2–4 个主角就够了。** 每个角色都要有固定的“标志物”：衣服颜色、发型、配饰（红围巾、头顶小芽、蝴蝶结）。同一个人换了身份（不同的前世、不同的年纪）也要留一个标志，观众才认得出来。
- 用 `person()` 的参数组合出角色，写进 `CAST` 对象，全片统一引用：
  ```js
  const CAST = {
    soul: { kind: 'kid', hairStyle: 'boy', hair: '#3b2c28', coat: '#e7ad55', pants: '#5b4a3e' },
    mom:  { kind: 'adult', hairStyle: 'long', hair: '#2f2422', coat: '#efe2cc', dress: true, scarf: '#d24f45' },
  };
  ```
- 主角之间的配色要拉开：一个暖色（黄、橙、红），一个浅色或冷色（米白、蓝）。
- 需要一个贯穿全片的**信物或母题**：《我记得》用的是装满记忆的包袱、红线和圆圈。信物要在开头出现、中间反复出现、结尾回收。

## 3. 把歌的结构变成故事结构

先按 LRC 时间轴把歌分段：前奏、主歌 1、副歌 1、主歌 2、副歌 2、间奏、尾奏（有制作人员行的话一般在尾奏）。

| 歌曲段落 | 故事里通常放什么 |
|---|---|
| 前奏（无歌词） | 片名纸片 + 世界观铺垫：角色在做出发前的准备（收拾行李、看着星空）。不要只放一个静止背景 |
| 主歌 | 叙事：一句一个动作，推动情节 |
| 副歌 | 情绪爆发：快切、蒙太奇、拥抱、心形爆开、闪白；重复的副歌每次换一组画面 |
| 歌词里的“回忆”“我记得” | 换一种色调（`K.memoryLook()` 泛黄加照片白边），观众一看就知道是过去 |
| 间奏（无歌词） | 旅程或时间流逝：坐船、奔跑、季节变化、成长蒙太奇；可以用 `E.e`（音量）让星星或灯随音乐闪烁 |
| 最后一句 | 回收开头的信物或母题，给一个完整的结局画面（特写、拥抱、红线系上） |
| 尾奏 / 制作人员 | 回忆墙（每一段的照片串在一起）+ 制作人员纸片 + 片尾标题 + 淡出 |

## 4. 一句歌词怎么“演”出来

每句歌词都问自己：**这一句里，谁在做什么，表情从什么变成什么？**

| 歌词类型 | 演法 |
|---|---|
| 具体动作（剪走、擦拭、跟在后面） | 直接演：道具 + 动作 + 对方的反应（被剪走行李的人哭了） |
| 比喻 | 还原成具体事件（“光圈”画成一圈圈纸环隧道） |
| 心理活动（不确定、怎么告诉你） | 表情 + 符号：`chip('？')`、思考气泡 `K.thought()`、打叉、省略号 |
| 对比（你记得 vs 你不记得） | 两个气泡对比：我的气泡里满是回忆，你的气泡里只有一个问号 |
| 相似（和你一样的笑） | 左右分屏，同一个表情，中间用撕纸线分开 |
| 时间流逝（收不到信） | 窗外季节变化（落叶 → 下雪），桌上的信不再增加 |
| 抽象概念（时空是个圆圈） | 画成图形化的隐喻：圆形小路，一个人直走、一个人转弯，最后在顶上相遇 |
| 重复的拟声（呜 呜） | 对应一个具体画面（婴儿在床里哭着伸手），每次重复时切回来 |

一句歌词里，动作的高潮最好落在那句唱到的关键词上：用 LRC 里那句的开始时间，加上关键词大概在句子里的位置。

## 5. 镜头语言清单

| 镜头 | 用途 | 引擎里怎么做 |
|---|---|---|
| 远景 / 建立镜头 | 每段开头交代环境 | 完整布景 + 小人物；`camera()` 缓慢推近 |
| 中景 | 两人互动 | 人物 h≈500–700 |
| 特写 | 情绪：表情、眼泪、笑 | `head()` 画大头，R≈200–260；配合 `tilt` |
| 分屏 | 对比、呼应 | 两次 `ctx.clip()` + 撕纸分割线 |
| 蒙太奇 | 副歌快切 | 一个镜头函数里按时间表切换子画面（见 `story_c.js` 的 `CHORUS`） |
| 镜中镜 / 照片 | 回忆的入口 | 墙上的相框里画下一段场景，再推进去放大成全屏（见 `story_b.js` 的 `shotFate`） |
| 运镜 | 别让画面死掉 | 平移：背景按视差分层移动；推拉：`camera(ctx, cx, cy, 1 + 0.05*ss(a,b,t))` |
| 主观视角 | 代入感 | 从婴儿视角往上看：俯身的人影、上方的灯 |

每个镜头至少要有一样东西在动：呼吸般的轻微摇晃、眨眼（`blink()`）、飘落物、缓慢推镜。

## 6. 转场清单

| 转场 | 场合 |
|---|---|
| 引擎默认的 0.12 秒溶解 | 普通切换（自动加，不用写） |
| 闪白 `overlay('#fffaf0', ...)` | 副歌快切、穿越、降生 |
| 淡黑 | 段落结束、片尾 |
| 推进相框 / 窗户 | 进入回忆、进入某个家 |
| 光圈隧道 `rings()` | 穿越、奔跑、时空转换 |
| 纸屑爆开 | 变身、消失 |
| 同一个形状衔接 | 上个镜头的圆（钟面）接下个镜头的圆（月亮） |

## 7. 分镜表模板

写进项目的 `STORY.md`：

```markdown
# 《歌名》分镜
一句话主题：……
角色：我＝……（黄外套、头顶小芽）；你＝……（红围巾）
信物 / 母题：……

| 时间 | 歌词（只写开头几个字） | 画面与动作 | 表情变化 | 转场 |
|---|---|---|---|---|
| 0:00–0:09 | 前奏 | 纸云滑入，片名纸片落下 | — | 淡入 |
| 0:28–0:33 | 我带着… | 小魂背着大包袱往水底游 | 吃力 worry | 水花 |
| … | | | | |
```

## 8. 自检清单

- [ ] 能用一句话说出这首歌的故事
- [ ] 每句歌词都有对应的动作，没有哪段只是“背景在动”
- [ ] 主角在每个镜头里都认得出来（配色、标志物）
- [ ] 表情会变化，至少有笑、哭、惊讶三种
- [ ] 副歌比主歌更热闹（快切、爆开、拥抱）
- [ ] 开头的信物在结尾被回收
- [ ] 前奏、间奏、尾奏都有设计
